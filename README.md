# Projeto Carteira de Cripto

Este workspace foi configurado para iniciar um projeto Java de carteira de criptomoedas.

## O que já está instalado / detectado

- Java 1.8 está no `PATH` do sistema.
- JDK local disponível em `oracleJdk-26` com versão Java 26.
- Extensões VS Code recomendadas instaladas: `redhat.java`, `vscjava.vscode-java-pack`, `vscjava.vscode-java-debug`, `vscjava.vscode-java-dependency`, `vscjava.vscode-maven`, `vscjava.vscode-gradle`.

## Próximos passos

1. Instalar um gerenciador de build se quiser usar Maven ou Gradle:
   - Maven: https://maven.apache.org/
   - Gradle: https://gradle.org/
2. Abra o workspace no VS Code.
3. Compile com Maven quando o `mvn` estiver disponível:
   ```bash
   mvn clean package
   ```
4. Comece a implementar as funcionalidades de carteira em `src/main/java/br/com/carteira/Main.java`.
